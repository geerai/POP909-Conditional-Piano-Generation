# Generated examples

`key-chord-v1/` and `key-chord-step2000/` contain paired generations for the
same ten test conditions and seeds. Each sample includes condition Melody,
condition Chords, reference Piano, generated Piano, combined MIDI, prompt and
output tokens, and a generation report.

These examples support a controlled comparison of the five-epoch model and the
longer 2,000-step run. They are demonstration artifacts, not the complete test
set.
