# Metadata

- `pop909-index.csv`: reproducible export of official POP909 meter metadata.
- `accepted-songs.json`: songs accepted by the POP909/POP909-CL audit.
- `excluded-songs.json`: songs excluded with explicit reasons.
- `audit-summary.json`: compact audit and conversion summary.

These files are metadata and audit evidence, not a redistribution of the MIDI
corpus. The full per-song audit is regenerated locally because it contains
machine-specific source paths.
