# Results

- `key-chord-10/`: detailed exploratory evaluation of the published ten-sample
  REMI run.
- `key-chord-100/`: aggregate evaluation of 100 distinct test windows.
- `grammar-comparison/`: paired five-epoch versus 2,000-step structural
  comparison for the same ten conditions and seeds.

The files preserve negative results as well as improvements. In particular,
the 100-sample run has zero strictly grammar-valid sequences, so its musical
metrics are diagnostic rather than a final benchmark.
